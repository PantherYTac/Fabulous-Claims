# Fabulous Claims

**Fabulous Claims** is a land protection plugin for Minecraft servers, offering both command-based and block-based claiming. Players can customize claim sizes and personalize enter/leave messages for a smooth, immersive experience.

## Features
- Command-based and block-based claiming
- Customizable claim sizes
- Personalized enter/leave messages
- Intuitive help menu and permission system
- Designed for clarity, fairness, and ease of use

## Installation
1. Drop the plugin JAR into your server’s `/plugins` folder.
2. Restart the server.
3. Configure settings in `config.yml` to match your server’s needs.
